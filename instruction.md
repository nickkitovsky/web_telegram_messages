# Я хочу создать python приложение, которое будет сортировать "Saved messages" в телеграм (сообщения отправленные самому себе) с помощью llm.
## Мой стек:
* uv как менеджер зависимостей
* python 3.14 установленный с помощью uv
* fastapi (как backend)
* sqlalchemy (для работы с базой данных)
* postgresql (с асинхронным движком)
* alembic (для миграций)
* Telethon (для получения сообщений из saved messages)
* TaskIQ (для запуска отложенных задач)
* llama-cpp-python (для запуска локального llm)
* datastar (для генерации frontend и интерактивного взаимодействия)
## Как будет выглядеть функционал приложения:
* Авторизация в приложении
* Форма авторизации для telethon через веб интерфейс 
* Веб интерфейс с сообщениями, llm определяет по содержимому tag для данного сообщения, и генерирует заголовок на основе содержимого сообщения
* В интерфейсе кнопки редактировать тег (если llm не смогла с высокой долей вероятности выбрать тег, предоставлять выбор наиболее вероятных тегов). 
* Так же должна быть возможность архивировать сообщения (скрыть из общей ленты) и удалить сообщение (из веб интерфейса и telegram). 
* Должен быть реализован поиск по тексту или по тегам, либо выводить список всех тегов.
* TaskIQ по расписанию запускает telethon для получения новых сообщений из saved messages, они сохраняются в базу данных (поля: id, text, tags, date, channel, title, archived).
* TaskIQ запускает после получения новых сообщений локальную llm для определения тегов и заголовков с помощью  llama-cpp-python
## Перед началом работы:
* Найди подходящую локальную llm для работы с llama-cpp-python которая будет работать на cpu на локальной машине или слабом vps.
* установи python 3.14 и необходимые зависимости с помощью uv.
* продумай архитектуру и структуру папок и базы данных соответствуя best practices для fastapi и postgresql соответственно. 
* Создай базу данных и необходимые таблицы для хранения сообщений.
